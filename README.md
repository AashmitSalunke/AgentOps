# Agent Dashboard

A lightweight React + Vite dashboard for managing agents, workflows, and analytics.

## Features

- Responsive dashboard layout
- Agent list and detail views
- Analytics and notifications pages
- Tailwind CSS styling
- Command palette component

## Getting Started

```bash
npm install
npm run dev
```

Open the local development URL shown in the terminal.

## Build

```bash
npm run build
```

## Project Structure

- `src/` — application source code
- `public/` — static assets
- `package.json` — dependencies and scripts
- `tsconfig.json` — TypeScript config
- `tailwind.config.js` — Tailwind CSS config

## Notes

This repo is intended as an agent dashboard prototype. Update the README with additional details as the project grows.
